marineGeochemFoam: A multipurpose framework for simulating reactive transport and biogeochemical cycling in marine sediments and at seawater-groundwater interfaces

Navid Ahmadi, Evgenii Kortunov, Karim Norouzi Moghanjoghi, Joonas J. Virtasalo, Muhammad Muniruzzaman

arXiv:2611.12926·physics.geo-ph·Published 2026-11-01

We present marineGeochemFoam, an open-source reactive transport modeling framework for simulating early diagenesis, sediment burial, submarine groundwater discharge, and biogeochemical cycling in marine sediments and groundwater-seawater transition zones. The code is implemented in the widely used numerical toolbox OpenFOAM and extends the capabilities of the existing diagenetic models by supporting, among other features, i) coupled reactive transport of dissolved solute and solid species, (ii) a flexible native reaction package, supporting arbitrary reaction networks with n-th order and Monod-type kinetics, and (iii) coupling with an external geochemical code, PHREEEQC, providing access to a wide range of thermodynamically based geochemical processes. We benchmarked different features of the code across various examples with increasing complexity. Successively, the code was applied to two case studies reproducing field observations from the Hanko groundwater discharge site, Finland, and the Santa Barbara Basin, California. Beyond diagenetic applications, the code also serves as a general-purpose reactive transport simulator.
